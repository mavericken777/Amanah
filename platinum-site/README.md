# Amanah public website

This Vite + TypeScript application builds the public Global Halal Supply Chain Limited website and its connected platform-tour pages. The protected Amanah application remains at the repository root.

## Current experience

- Black-and-gold institutional design with Arial-family typography.
- The homepage explains the product journey with connected, information-bearing process visuals and links to detailed ecosystem sections.
- The full journey covers manufacturer onboarding; premises, product and SKU; materials and suppliers; applicable requirements; laboratory evidence; audit and corrective action; production; warehouse and logistics custody; ports/customs; GCC receiving, distribution and verification; and continuous monitoring.
- AHTE ⇄ Direct JAKIM API ⇄ JAKIM; China → GCC direct.
- AI/ML monitors evidence and operations, predicts risk and recommends preemptive strategies. JAKIM/JAIN/JAIM, muftis, scholars and authorised halal auditors decide certification award and revocation.
- Public pages use system/browser fonts and respect reduced-motion and reduced-transparency preferences.

## Local commands

```bash
npm install
npm run dev
npm run build
npm run preview
npm run quality:budget
npm run quality:promotion
```

The repository CI checks the website build, responsive behavior, accessibility, browser journeys and performance. GitHub Pages publishes the generated public routes.
