    workflow

    The complete audit session

    AI may highlight missing evidence, anomalies, contradictions, possible duplication and control relevance. The auditor owns the finding. Formal certification remains with the competent authority.

    1. Auditor + device + MFA
    2. Assigned audit
    3. Verify facility / scope

    device

    Identity precedes the device interaction

    Capture

    Camera, still/video, microphone and dictated notes; QR, barcode, DataMatrix and OCR. NFC and location only where approved.

    Trust

    Device certificate, secure clock, role/scope permissions, auditor identity, MFA and hardware-backed keys where available.

    Offline

    Encrypted local storage, assigned signed requirement snapshot, local evidence hashing, queue and credential expiry/revocation cache.

    Reconciliation

    Server validation, event sequence, signature and replay checks, commit and acknowledgement. Conflicts are surfaced; originals are preserved.

    evidence

    One observation, an attributable evidence object

    Capture context, identifier and observed condition. Original media remains immutable; annotations are separate linked objects.

    Technical detail

    EvidenceID, ObjectID, AuditID, RequirementID, HCPID, ActorID, Timestamp, DeviceID, LocationID where appropriate, MediaHash, SourceType, Description and IntegrityProof. Sync state and evidence type belong to the adapter contract.

    safety

    Designed for a real facility

    Authorized packages load only audit-relevant data. Factory PPE and safety rules govern device use. The session supports pause/lock and avoids distracting overlays around hazardous machinery.
