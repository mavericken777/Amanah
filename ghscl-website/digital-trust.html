Every object has a context.

Choose a node to inspect its designed relationships and evidence obligations. No production identifiers, evidence counts or timestamps are fabricated.

intelligence

The intelligence layers

Standards and applicability

Resolve authoritative instrument, version, requirement and applicability before choosing controls. Missing licensed text remains source-locked.

Evidence intelligence

Bind source records, actors, devices, timestamps, custody and integrity proofs to the exact object and control.

AI assurance

Surface gaps, anomalies, contradictions, changes and potential trust fractures. Preserve evidence references and model/version provenance for human review.

Digital twins

Facility, material, sample, batch, lot, pallet, shipment, container and seal objects carry identity, events, relationships and evidence. A render alone is not a live twin.

integrity

Integrity protects history; it does not create truth

A hash detects alteration relative to a known digest after creation. It does not independently prove the source claim. Trust also depends on verified source, authenticated actor, custody, scope and accountable review. Blockchain is an optional integrity anchor, not the authority root.

  1. Evidence payload
  2. Canonicalization
  3. Content hash
  4. Issuer signature
  5. Timestamp / registry
  6. Optional external anchor
  7. Verification
Technical detail

Corrections create a new version plus an authorized supersession event, reason and new integrity proof. Original media and historical records remain preserved. Signature checks also require trusted keys, validity and revocation checks.

state

Three different views of status

System trust state

Object-scoped evidence and control state: incomplete, assessed, HOLD, corrective action, re-verification, quarantine or recall as applicable.

Formal certification state

An external competent-authority decision with issuer, mandate, scope, validity, conditions and authenticated evidence. It is never inferred from a hash or AI score.

Operational release

A separate internal gate after required controls and destination conditions pass. It cannot replace certification or import clearance.

Technical detail

Conceptual uppercase lifecycle terms in the China execution model are not a new executable enum. The pinned canonical authority_decided machine state has no onward transition. Source governance must resolve vocabulary and transition conflicts before promotion.

monitoring

Exceptions travel with their affected objects

Event ingestion, rules, geofencing and anomaly detection can identify expired evidence, custody breaks, seal mismatch, HCP/SCCP deviations, temperature excursions or destination rejection. The response is HOLD, scoped impact analysis, human review and re-verification—not a compensated aggregate score.

Technical detail

Examples include LAB_RESULT_LINKED, SUPPLIER_CHANGED, HCP_EXCEPTION, SEAL_APPLIED, ROUTE_DEVIATION, DESTINATION_RECEIVED and AUTHORITY_STATUS_UPDATED. These are architecture examples; connector event mapping must match its approved source contract.

connectors

Replaceable connectors. Explicit trust boundaries.

Authority Gateway

Official authority references, signed decisions, case/status synchronization and revocation. No official JAKIM endpoint is invented.

LabConnector

Sample, accession, method, result, custody, authenticated evidence and amendment/versioning.

LogisticsConnector

Booking, container, seal, custody, condition, geofence, exception and receiving events.

Factory connectors

ERP, MES, QMS, WMS, LIMS and IoT adapters exchange stable IDs, source versions, timestamps and integrity metadata.

security

Federation with selective disclosure

Detailed records stay within their governed source domains. Cross-border exchange uses authorized assertions, references, hashes, status and minimum necessary metadata. Manufacturer, auditor, authority, lab, importer and consumer views follow role, organization and purpose boundaries.

Technical detail

Security architecture includes MFA, least privilege, RBAC/ABAC where applicable, encrypted transport/storage, device identity, protected keys, revocation, replay prevention, idempotency and append-only audit history. Connector health and processing errors should be observable without logging sensitive payloads.
