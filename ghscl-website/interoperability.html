Supported integration patterns

Synchronous

REST, SOAP and XML interfaces with versioning, idempotency, timeout and retry controls.

Enterprise and legacy

EDI, CSV, SFTP and batch exchange for systems that cannot expose modern APIs.

Event-driven

Queues, event streaming and webhooks for operational changes, telemetry and status propagation.

security

Integration security and lifecycle

OAuth/OIDC where appropriate, mTLS, PKI, device certificates, rate limits, secrets management, versioning, deprecation, UAT and rollback controls are applied without fabricating partner or authority activation.

copilot

AI-assisted schema integration

The integration copilot can compare partner schemas with the AMANAH canonical model, identify field gaps, propose mappings and test payloads, and run compatibility checks. Compliance-critical transformations require human approval and immutable mapping history.

How this capability connects

This workflow is linked to AMANAH standards, evidence, authority, custody and governance controls so viewers can understand the operating process without internal engineering metadata.
