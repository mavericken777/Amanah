# Manufacturer cinematic experience — milestone 1

This route is the first incremental milestone for the Amanah manufacturer-facing experience.

## Route
- Next.js App Router: `/manufacturers`
- Existing public reference retained: `ghscl-website/manufacturers.html`

## Included in this milestone
- Responsive editorial hero with a dark obsidian palette and restrained gold/green accents.
- CSS-generated abstract trust geometry (no stock photography or external assets).
- Accessible navigation, skip link, visible keyboard focus and reduced-motion handling.
- Pointer-parallax on the abstract hero illustration.
- Initial four-step operating flow to preserve the reference content direction.
- Metadata and Open Graph metadata.

## Not yet included
The pinned GSAP/ScrollTrigger 20-step sequence, Lenis integration, section-mask transitions, interactive control matrix, five-area readiness checker and full motion QA are intentionally deferred to subsequent milestones. The current root package uses Next.js 16 App Router; it is not being downgraded to Next.js 14.
