External authority and transaction gates remain explicit: licensed normative text, competent-authority decisions, laboratory accreditation/results, manufacturer/SKU evidence, GCC import acceptance, carrier/warehouse qualification, real device provisioning, real buyer/importer/PO and Shipment 001.
