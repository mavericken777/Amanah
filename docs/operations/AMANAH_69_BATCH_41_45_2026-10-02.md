## 41. Manufacturer Command Center
Manufacturer users require an operational picture scoped to their organization: readiness; facility/product/SKU/material graph; document/evidence completeness; lab/sample state; audit findings/CAPA/re-verification; production monitoring; warehouse/shipment/custody; exceptions/alerts; upcoming expiry/action queue. The existing protected lifecycle pages and Command Center data are the implementation base. No manufacturer view may show another tenant's records or imply authority approval.

## 42. Authority Command Center
Authority experience is a distinct view, not a platform-admin view. It separates:
- external/formal authority state;
- AHTE trust state;
- operational release state;
- customs state;
- finance/Takaful state.

D5/D6 are human/sovereign. AHTE may assemble evidence, assess D0–D2 and apply configured D4 holds; it cannot synthesize an authority decision or release a sovereign hold.

## 43. Product verification
The implemented `public-verify` Edge Function accepts only issuer-authorized disclosure tokens, hashes the token, resolves a non-revoked/non-expired verification, binds it to the same-organization trust packet and returns packet type/schema/status/content hash plus the authorized disclosure. The response explicitly carries `not_certification: true`. Public UI cannot search private factory data by product/batch/shipment identifier.

10. Technology/system/device providers — ERP/MES/QMS/WMS/LIMS/IoT/DMS/identity/integrity interfaces; no certification authority.
11. Auditors/Halal officers/authorized human reviewers — human assessment/review according to mandate.

Partner status must be sourced. A meeting, proposal, architecture entry or integration adapter does not establish a signed partnership or production authorization.

## 45. Stakeholder playbook contract
Every stakeholder playbook SHALL contain: purpose; legal/operating role; owner; onboarding prerequisites; inputs; outputs; evidence produced/consumed; system of record; integration points; security/data boundary; RACI; decision boundary; exception/escalation route; KPI/SLA proposal; test/UAT checklist; production activation gate.

Role-specific minimums:
- Manufacturer: facility/product/material readiness → evidence → audit/CAPA → authority workflow → continuous monitoring.
- Laboratory: sample → custody → method/QC → result → review/signature → evidence; NOT_DETECTED ≠ HALAL.
- Sinotrans: warehouse receipt → storage → dispatch → pickup → container/seal → port handoff → transit → destination receipt/POD.
- Port/customs: lookup trust → inspect/sample/hold/release/custody under sovereign mandate.
- GCC importer/destination: acceptance/import controls → receiving → warehouse/distribution → verification.
- JAKIM/authority: receive scoped evidence → human review/decision → signed external authority reference/status.
- Finance/Takaful: receive purpose-limited evidence packet → independent decision; AHTE does not approve.
