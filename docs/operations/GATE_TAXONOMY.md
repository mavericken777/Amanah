# Completion gate taxonomy

- `DOC-COMPLETE` — documentation/control architecture present for snapshot.
- `SOURCE-VERIFIED` — controlling source held/verified to claimed depth.
- `SOURCE-LOCKED` — exact authoritative/licensed source depth unavailable; no invention permitted.
- `EXTERNAL-GATE` — requires third-party/authority/commercial evidence or action.
- `TRANSACTION-GATE` — cannot exist until a real SKU/order/shipment/workspace event exists.
- `ENGINEERING-GATE` — architecture exists but implementation/testing/environment closure remains.

These statuses describe evidence readiness; none creates certification authority.
