# GHSCL Temporary Website — Free Hosting

The static stakeholder site is in `ghscl-website/`.

## GitHub Pages

The repository already contains a Pages deployment workflow.

GitHub Pages is available for public repositories on GitHub Free; private repository Pages requires GitHub Pro, Team or Enterprise.

Amanah is private. Therefore a zero-cost temporary publication requires either a GitHub plan that supports Pages for the private repository or moving only the static website to a separate public repository.

## Cloudflare Pages

The website can also be deployed as a static site to Cloudflare Pages without a database.

## Publication safety

The website deliberately does not invent GHSCL corporate registration data, directors, address, phone or email. Add only GHSCL-approved official information before publication.

Use the provider-assigned temporary subdomain during stakeholder review; connect the official domain after DNS ownership and corporate approval are confirmed.
