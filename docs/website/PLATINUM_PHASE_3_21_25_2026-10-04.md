## Promotion design

The current generated `ghscl-website/` remains the source for all secondary public pages. The deployment workflow:

1. verifies current main and exact-head CI;
2. builds/lints the existing ecosystem pages;
3. builds and quality-checks `platinum-site/`;
4. overlays the platinum `index.html` and hashed `assets/` into the deployment artifact;
5. preserves `verify.html`, `manufacturers.html`, `corporate-profile.html` and other existing public routes;
6. deploys through GitHub Pages;
7. verifies deployed HTML byte-for-byte against the exact built artifact.

This removes the prior parallel-site gap without redesigning protected Amanah application routes.
