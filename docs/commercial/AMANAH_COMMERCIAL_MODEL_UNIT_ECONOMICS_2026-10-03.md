## 1. Commercial architecture

Revenue families:
1. Enterprise onboarding / readiness programme
2. Platform subscription
3. Facility / product / SKU assurance scope
4. Integration implementation and maintenance
5. Command Center managed operations
6. Evidence / event volume services
7. Verification / disclosure services
8. Smart-audit enablement
9. Hardware / device procurement or managed hardware
10. Training academy
11. Partner implementation / programme management
12. Finance/Takaful evidence-interface services where permitted

Third-party pass-through or separately contracted items:
- laboratory testing;
- audit travel / field services;
- freight and warehousing;
- port/customs charges;
- hardware OEM costs;
- cloud/SMS/identity consumption;
- insurance/Takaful premium;
- financing cost;
- authority/statutory fees.

## 2. Unit economics model

For one customer / programme period:

`Revenue = Onboarding + Subscription + Integration + ManagedOps + Usage + Training + HardwareMargin + ApprovedServices`

`DirectCost = Cloud + Support + IntegrationLabour + CommandCentreLabour + HardwareCOGS + ThirdPartyPassThrough + Travel + PaymentFees`

`GrossProfit = Revenue - DirectCost`

`GrossMargin% = GrossProfit / Revenue`

`Contribution = GrossProfit - VariableCommercialSupport - VariablePartnerCost`

`CAC Payback Months = CAC / MonthlyContribution`

No numeric margin or CAC claim is controlling until real contracts and cost evidence exist.

## 5. Customer value / cost avoidance hypotheses

These are hypotheses requiring validation, not guaranteed savings:
- reduced manual evidence reconciliation;
- fewer repeated partner data requests;
- faster exception assignment;
- narrower recall blast radius;
- reduced duplicate integration work;
- better audit readiness;
- clearer receiving verification;
- earlier detection of expired/missing evidence.

## 6. Commercial packages

### Foundation
Identity, onboarding, facility/product/supplier/evidence baseline, standard support.

### Corridor
Foundation + laboratory evidence + audit + logistics/custody + verification.

### Platinum
Corridor + real-time monitoring + selected hardware/device stack + 24/7 Command Center + predictive/preemptive workflows.

Package names do not imply certification status.

## 7. CODA / hardware financing interface

Hardware 3/5/7-year financing scenarios remain commercial proposals until financier, customer, OEM, tax, currency, residual-value and credit terms are validated. AMANAH/AHTE does not approve financing.

## 8. Governance

Every commercial quote must identify:
- scope;
- assumptions;
- exclusions;
- validity period;
- currency;
- tax treatment;
- third-party pass-through;
- change-control mechanism;
- authority/partner dependencies;
- payment milestones;
- acceptance criteria.
