# AMANAH / Global Halal Digital Trust — Corporate Profile

**Version:** 1.0.0 | **Control date:** 2026-10-02

AMANAH is a digital trust and operational-assurance infrastructure connecting origin, organisation identity, facility, product/SKU, supplier/material provenance, controlled evidence, AI-assisted review, human governance, laboratory evidence, audit, corrective action, competent-authority workflows, production monitoring, warehouse/logistics custody, border interfaces, destination operations and product verification.

**Canonical lifecycle:** Origin/Manufacturer → Organisation → Identity/KYC → Facility → Product → SKU → Supplier → Ingredient/Raw Material → Documentation/Evidence → AI-assisted review → Human governance → Laboratory → Audit → Corrective Action → Authority/Certification workflow → Production → IoT → Batch → Warehouse → Logistics → Digital Chain of Custody → Port/Regulatory Connectivity → Cross-Border Movement → Destination → Distribution/Retail → Product Verification → Command Centre → Continuous Assurance.

**Authority boundary:** AHTE ⇄ Direct JAKIM API ⇄ JAKIM. AMANAH does not create Halal certification, sovereign release or regulatory decisions. AI assists; authorised humans and competent authorities decide.

**International model:** China → GCC direct is the default physical corridor. Malaysia is the governance/assurance/authority-connectivity plane unless separately scoped.

**Trust model:** ObjectID + EventID + EvidenceID + ActorID + Timestamp + IntegrityProof. Hashes evidence integrity; they do not by themselves prove the truth of the underlying claim.
