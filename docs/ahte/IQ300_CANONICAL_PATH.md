# Connected Assurance Journey

`Premises + Product/SKU → applicable requirements → controls + HCP/SCCP → evidence → laboratory + audit → certification review and decision → corrective action + re-verification → production + custody → destination verification → continuous monitoring`

The platform connects the full evidence and operating journey. JAKIM/JAIN/JAIM, muftis, scholars and authorised halal auditors decide certification award or revocation. The system records the decision, source, actor, timestamp and supporting evidence, then propagates its status to affected product, premises and supply-chain records.
