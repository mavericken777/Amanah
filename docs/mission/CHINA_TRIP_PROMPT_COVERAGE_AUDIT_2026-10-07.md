It also requires product-specific / technical MS applicability, with the current verified supplemental example:

- MS 2683:2017 — Kelulut (Stingless bee) honey — Specification.

It further requires MPPHM 2020, MHMS 2020, HAS, IHCS, protocols, circulars, authority instructions, destination requirements and laboratory methods.

Therefore the master prompt no longer permits an MS 1500 / MS 2400-only representation of the platform.

## External-presentation simplification

The master prompt deliberately removes internal repository-control language from the stakeholder delivery layer.

Instead of repeated engineering / status language, it uses one clean presentation principle:

- present complete platform capability;
- state an external approval / contract / production connection as executed only when evidence exists;
- avoid repeating that qualification across every slide/page.

This keeps the China-trip materials polished without changing actual authority or security boundaries.

## Definition of completion

The prompt is considered complete only when all major stakeholder questions can be answered from finished deliverables and the output package contains usable:

- PPTX;
- PDF;
- DOCX;
- XLSX where appropriate;
- PNG/SVG;
- website/offline website;
- video production package / generated media where available;
- master ZIP / offline binder.

Markdown source files alone do not satisfy the China-trip delivery standard.
