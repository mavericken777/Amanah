## 5-minute executive walkthrough

1. **China Mission Showcase** — establish the operating proposition: China → GCC direct; Malaysia as governance/assurance/standards/authority-connectivity plane.

## 30-minute technical / institutional walkthrough

Use the 15-minute flow, then expand:
- Standards: registry, applicability, controls, HCP/SCCP, evidence and source-lock.
- Evidence binding: ObjectID + EventID + EvidenceID + ActorID + Timestamp + IntegrityProof.
- Trust lifecycle: INITIAL → EVIDENCE-COMPLETE → ASSESSED → VERIFIED → RELEASED, with exception states.
- Decision classes D0–D6.
- Laboratory chain: request → sample → seal → custody → accession → method/QC → result → review/signatory → report/evidence.
- Audit chain: assignment → scope → object scan → evidence capture → AI assist → auditor assessment → finding/CAR → CAPA → re-verification.
- Continuity: capture → hash/sign → encrypted local buffer → reconnect → sequence/replay check → commit → acknowledge.
- Recall/blast radius: material → batch → SKU → shipment → container → importer → warehouse → distributor → retailer → public verification state.

## Counterparty-specific pivot

- **CODA:** manufacturer mobilisation, hardware/deployment readiness, candidate pipeline.
- **Laboratory / scientific institution:** sample/evidence chain, methods/QC, integration and hard boundary that NOT_DETECTED ≠ HALAL.
- **Sinotrans:** warehouse, fleet, container/seal, telemetry, custody, exceptions, port handoff.
- **Traceability platform:** serialization, aggregation, anti-counterfeit/anti-diversion, API/schema mapping.
- **LuLu / MAF / Tamimi / noon:** importer/retail listing, receiving, SKU/batch eligibility, disclosure and recall.
- **BORONEX / technology:** device/system evidence outputs, integration, maintenance/calibration and control mapping.
- **Macau / institutional:** ecosystem cooperation, business matching and workstream governance.

## Demo-data rule

The public interactive journey uses an illustrative reference product/batch/shipment so the full mechanics can be demonstrated consistently. It is distinct from **[PILOT: Shipment 001 — NOT-INSTANTIATED]**. Do not replace the illustrative record with invented live commercial data.

## Meeting close

Before ending each meeting capture:
- exact counterparty legal entity;
- named executive, operational and technical/compliance owner;
- scope/site/lane/product/SKU/system;
- documents/evidence shown;
- API/data owner and sandbox/UAT path;
- decisions and open questions;
- actions with owner/date;
- next meeting / decision gate.

The demonstration is complete when the counterpart can describe the flow from manufacturer → evidence → custody → GCC importer → distributor → retailer → verification and understands which decisions remain with competent authorities.
